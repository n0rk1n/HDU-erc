# Prompt 变体实验结论

> **状态：探索性 pilot 已于 2026-08-03 冻结。** 原始预测、指标和排序仅供追溯。

## 探索性观察

- 领先趋势：`prompt_no_label_guidance`，Accuracy 59.38%，相对 `full` 点估计 +3.12%，配对 95% 区间 -3.12%–+9.38%。
- 领先趋势：`prompt_coarse_to_fine`，Accuracy 59.38%，相对 `full` 点估计 +3.12%，配对 95% 区间 -3.12%–+9.38%。

## 冻结决定

- 本实验使用官方 test 的 64 条平衡 seed 进行 Prompt 筛选，因此不属于未触碰的最终测试。
- 不再基于这 64 条继续调参，不把上述趋势称为第二阶段候选，也不据此直接运行完整 2,542 条 test。
- 下一道实验门槛是完成输入—标签对齐审计，并把后续 Prompt 选择迁移到 validation split。

## 边界声明

- 64 条 seed 结果只能作为探索性观察，不能作为最终结论。
- 当配对差值区间包含 0 时，不能表述为已经证明提升。
