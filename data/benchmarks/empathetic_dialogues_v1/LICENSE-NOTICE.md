# License and attribution

The source data is **EmpatheticDialogues** by Hannah Rashkin, Eric Michael
Smith, Margaret Li, and Y-Lan Boureau. The upstream repository distributes it
under the [Creative Commons Attribution-NonCommercial 4.0 International
license](https://creativecommons.org/licenses/by-nc/4.0/).

This directory contains a converted subset of that material. The conversion
changes the storage format, restores the upstream `_comma_` placeholder, and
selects the last utterance from the original situation speaker as the current
classification input. These changes do not remove the upstream attribution or
non-commercial restriction.

Source and citation:
