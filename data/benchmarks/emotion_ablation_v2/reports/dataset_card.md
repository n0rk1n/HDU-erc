# Dataset Card

Emotion Ablation V2 is a bilingual benchmark package for emotion-recognition ablation experiments.

Version `0.1.0` contains a 500-record formal release plus a 64-record seed set. The formal release is split into `core_parallel`, `extended_independent`, and `challenge` records so experiments can report both headline metrics and harder diagnostic slices.

The seed set remains as a compact reference for annotation style, bilingual pairing, and future expansion examples.

The benchmark uses Chinese and English records with reviewed labels from the supported 32-label taxonomy.
