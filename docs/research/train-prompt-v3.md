# 从训练集标注习惯生成 Prompt v3

本轮只调整 prompt，不改变标签定义、families、检索、4 条示例、解析器或评分器。v1/v2 保留原文。新版使用独立 `native-labels-v3`，尚需真实验证才能判断效果。

## 数据依据

训练审计工件：`df0b445f-fe1b-4bea-bcb1-961f99778c41`。完整统计、抽样原文、标签及 source_id 在 `data/research/train_prompt_v3_audit.json`，生成脚本为 `scripts/audit_train_prompt_v3.py`。脚本核对官方 manifest 哈希，只读取 train.tsv 和 emotions.txt，不读取 dev/test 内容。正则仅用于分析切片，不进入分类器。

43,410 条训练评论中，36,308 条（83.64%）单标签，6,541 条双标签，532 条三标签，28 条四标签，1 条五标签。12,823 条仅 neutral，1,396 条 neutral 与其他标签共现。

| 观察 | 训练证据 | Prompt 调整 |
|---|---|---|
| 多标签不是多个备选答案 | 单标签 83.64%，同时保留 2–5 标签真实共现 | 先选最贴切的解释，只为额外、明确的情绪信号增加标签；不强制单标签，不使用输出配额 |
| 负面词不能直接判情绪 | 包含 wrong/stupid/dumb/bad/terrible 的 1,636 条中，318 条仅 neutral；disapproval 177 条 | 判断态度和说话目的，不把 disapproval 作为负面文本的兜底标签 |
| 脏话不是固定标签 | 1,665 条脏话切片中，250 条仅 neutral，另有 anger、annoyance、admiration 等 | 结合语气与对象，避免词语触发式归类 |
| 疑问句需区分兴趣与困惑 | 4,581 条含问号评论，curiosity 1,771、confusion 699、仅 neutral 1,097（标签支持可能重叠） | 信息询问可以表达好奇；理解困难偏困惑，反问按实际态度判断，不要求出现 curious |
| 直接情绪线索仍有价值 | thanks/thank you 切片 2,224 条中 gratitude 2,156；笑声切片 1,906 条中 amusement 1,463 | 保留明确线索，不因 neutral 校准而抹去真实情绪；不将词语比例变成硬规则 |
| 定义可能比原始标注更窄 | `efc4vu1`、`ed4qo03` 的同情性 sorry 被标注 remorse；`eetnbzk` 的更正道歉也是 remorse | 不再将 remorse 限制为承认自己做错事；保留不同标注用法的说明 |
| 近邻文本标签不是候选范围 | 分层样本及词形切片存在相似词语、不同标签的实际记录 | 检索例子用于了解标注习惯；输入证据优先，仍可选择检索中未出现的任何原生标签 |

这些是结合训练样本作出的操作性假设，不是声称数据集每条标注都能被规则解释。没有重新标注、删除难例，或把开发集答案嵌入 prompt。

## 对照协议

- 在相同 dev200 上重新运行 v2 控制组和 v3 候选组，每组 200 条；只允许 name 与 prompt_version 不同。
- 两组均使用原有 contrastive-v1、候选 50、k=4、同一模型参数、同一 train 库及原生多标签评分。运行前冻结两组；结束后核对实际入选示例、顺序和全文完全相同。
- 主指标仍为细类 Micro-F1 / Macro-F1 和精确标签集合匹配率；不通过换为宽松命中率宣布改进。
- 前轮 dev200 的错误已被观察，并用于提出本轮问题，因此本轮属于开发集迭代，不是独立泛化结论。官方 test 不使用。
- 只冻结一个 v3 候选；不按本轮 dev 得分继续改写或选择 prompt。
- 记录原始请求响应、重试、usage、完整代码及 prompt 快照、配对 bootstrap、训练审计、评分与备份。

审计修订说明：初版审计读取器处理了原文外层引号，280 个抽样记录中 1 个出现文本差异；已按 TSV 的 QUOTE_NONE 修正，并验证所有统计、prompt 和运行时导入文本不变。旧工件保留，纠正关系通过 train_audit_correction 工件记录。
