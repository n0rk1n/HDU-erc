## 结果解释边界

本轮同时修改 prompt 与 example，只能检验组合效果。若后续真实结果有提升，还需补单独更改 prompt、单独更改 example 的消融，并扩大开发集、最终冻结方法后使用 test。11 组语义相邻关系是人工先验，不是已测量的混淆矩阵，不能据此宣称研究创新已经成立。
