# 情绪识别消融实验大白话汇报稿设计

## 目标

生成一份与现有导师汇报 PPT 配套的中文 TXT 口述稿，帮助用户在约 15 分钟内以自然、非术语堆砌的方式说明实验背景、目标、准备工作、结果边界、反思和下一步。

## 受众与语气

- 受众：导师；默认具备研究方法背景，但不要求提前记住项目细节。
- 语气：第一人称、诚实、具体、自然口语；避免把探索性结果说成最终结论。
- 篇幅：约 1,200–1,500 字，可作为 15 分钟汇报的主讲稿；保留关键数据，其他内容以解释为主。

## 内容结构

1. 开场与背景：项目是对话情绪识别，想知道性能来自哪个 Prompt 组件。
2. 目的：比较动态示例、历史情绪和上下文长度，并建立可信的实验解释边界。
3. 准备与做法：64 条合成 seed、32 中/32 英、32 类情绪、5 组配置、320 次成功调用、Accuracy 与 Macro F1。
4. 主要发现：静态示例组 79.69% / 74.60% 优于 full 的 71.88% / 65.76%；zero-shot 67.19% / 60.83% 更弱；中英文趋势一致。
5. 反思：两个预期消融组与 full 的 Prompt 64/64 相同，故不能归因；zero-shot 是组合消融；样本小、合成数据、无 high-context、评估的是 Codex CLI Agent。
6. 下一步：补长上下文与 high-context、增加非泄漏历史先验、拆开组合消融、重复试验并加入置信区间/裸 API。
